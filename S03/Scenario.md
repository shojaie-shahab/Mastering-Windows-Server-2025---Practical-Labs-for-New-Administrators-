# Chapter 03 – Active Directory Scenario

## Company
DevLab

## Scenario Overview
DevLab requires a secure Active Directory infrastructure for authentication and management across HeadOffice and Branch.

## Requirements / Tasks
1. Build the first Domain Controller (devlab.local)
2. Add an Additional Domain Controller for redundancy
3. Create OU structure and users
4. Implement Fine-Grained Password Policy
5. Configure Trust between domains (optional)
6. Manage FSMO roles
7. Deploy Read-Only Domain Controller (Branch)
8. Simulate DC failure and demotion

## How to use Lab-Implementation
Each requirement has a corresponding Lab file in the Lab-Implementation folder:
- Requirement 1 → 01-Build-Domain.md
- Requirement 2 → 02-Additional-DC.md
- Requirement 3 → 03-Users-and-Groups.md
- Requirement 4 → 04-Password-Policy.md
- Requirement 5 → 05-Trust.md
- Requirement 6 → 06-FSMO.md
- Requirement 7 → 07-RODC.md
